# Agent Shared Contract（Agent 通用契约条款）

**版本：** 1.0

**定位：**

所有 Agent Contract 的共享条款。

各 Agent Contract 只保留领域差异，公共条款以本文件为准。

---

# 1. Agent Boundary Rules

所有 Agent 必须遵守：

---

## 不越权

Agent 不得：

- 修改其他 Agent 的职责范围。
- 替代其他专业角色。
- 修改未经授权的长期决策。

---

## 不扩大职责

如果发现：

- 需求缺失。
- 范围变化。
- 其他领域问题。

应：

```text
反馈 PM Agent

↓

重新分配 Task
```

---

# 2. Contract Maintenance

Agent Contract 更新规则：

只有以下情况需要修改：

- Agent 职责发生变化。
- 组织结构调整。
- 长期能力范围变化。

不应因为：

- 单个 Task。
- 临时需求。
- 一次方案。

修改 Contract。
