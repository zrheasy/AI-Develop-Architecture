# BASIC MAPP（Basic Minimal AI Project Protocol）

**版本：** 2.0

**目的：** 为 AI 长期参与软件研发提供极简、稳定、可持续的多 Agent 协作协议。

## 1. 核心目标

让 Agent 用最少的上下文理解项目、执行当前任务，并交付可被后续工作继续使用的结果。

协议只保留长期、通用的规则；特殊情况不写入基础协议。

## 2. 核心文件

| 文件 | 内容 | 质量标准 |
|---|---|---|
| `PROJECT.md` | 项目稳定上下文 | 30 秒内理解 |
| `ACTIVE.md` | 当前工作上下文 | 10 秒内理解 |
| `DECISIONS.md` | 长期决策索引 | 5 分钟内理解关键决策 |

超过标准则压缩现有内容，不通过新增文档解决复杂度。

## 3. 最小工作流程

1. 读取 `PROJECT.md`，理解项目目标与边界。
2. 读取 `ACTIVE.md`，确认当前状态、任务与下一步。
3. 仅在任务相关时读取 `DECISIONS.md`。
4. 获取完成当前任务所需的最小上下文。
5. 在职责范围内执行，优先复用，不扩大任务范围。
6. 验证结果，确保交付物可被后续工作继续使用。
7. 任务或项目状态发生变化时，更新对应的 `ACTIVE.md`；产生长期决策时，更新 `DECISIONS.md`。

## 4. 信息记录原则

只记录未来仍会影响工作的最终信息：

- 决策：记录结论、原因与影响。
- 状态：记录当前真实状态、下一步与阻塞。
- 不记录讨论过程、临时想法或已经由 Git 保存的内容。

## 5. 基本行为原则

- 先理解，再行动。
- 只读取完成任务所需的信息。
- 优先复用已有规范、代码与资产。
- 保持最小修改，不处理无关问题。
- 代码与文档冲突时，以代码为准，并修正文档。
