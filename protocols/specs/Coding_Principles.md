# AI Coding Principles

**版本：** 1.0

**定位：** 开发类 Agent（Frontend / Backend / Mobile）的通用编码准则，是各 contract「工程实现门禁」的通用基线与引用依据；本文件是唯一权威，各 contract 不重复定义。

**适用范围：** 所有开发类 Agent 的代码修改、数据访问与上下文处理。

---

# 1. 代码组织

1. 按业务领域组织代码；文件单一职责，避免巨型文件和万能 `utils` / `common`。
2. 文件、目录、函数和类型名称必须明确表达职责。
3. 保持模块边界清晰、依赖浅层、显式，避免循环依赖和隐式行为。
4. 不重复定义类型、规则和功能；每个事实只有一个权威来源。
5. 优先简单、直接、可定位的实现，不为抽象而抽象。

# 2. 修改流程

1. 修改代码遵循：定位 → 阅读 → 修改 → 测试 → 验证。
2. 按需读取项目，不扫描无关文件；先定位，再读取。

# 3. 数据与上下文

1. 数据库只查询当前任务需要的数据，禁止无目的全量查询。
2. Context 只保留当前任务需要的信息；大型数据留在外部存储。

# 4. Prompt 与文档

1. 保持 Prompt 前缀稳定：静态内容在前，动态内容在后；新增内容优先追加。
2. `AGENTS.md` 只保存必须遵守的规则；详细知识按领域放入 `docs/`。
